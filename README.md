
# soporte-ti-branching
# Manual de Soporte TI Documentación básica para resolver incidencias comunes.

----------------------------------------
## Problemas de usuario

1. Restablecer contraseña
2. Revisar permisos
3. Verificar acceso a red
----------------------------------------
## Problemas de red

Si no hay conexión:

1. Verificar cable
2. Reiniciar router
3. Ejecutar ipconfig
----------------------------------------

## Problemas de equipo lento

Si el equipo funciona con lentitud:

1. Reiniciar el equipo
2. Cerrar programas innecesarios desde el Administrador de tareas
3. Liberar espacio en disco
----------------------------------------
## Problemas de impresora

Si la impresora no imprime o no es reconocida por el equipo:

1. Revisar conexión USB
2. Verificar drivers
3. Reiniciar spooler
